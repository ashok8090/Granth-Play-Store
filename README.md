ग्रंथ प्रबंधन 1.0.1

APK aur AAB GitHub Release pe nahi hain. Dono ek saath Actions se bante hain.

Download: Actions tab → latest **Android APK** run → artifact `granth-prabandhan-1.0.1`

- Package: `com.wnm.granthprabandhan`
- versionName: `1.0.1`
- versionCode: `16`
- Phone ABIs only: `armeabi-v7a`, `arm64-v8a`
- Sideload APK uses the same debug signature as the earlier Actions builds, so it can update that install. A satlok-signed APK cannot.
